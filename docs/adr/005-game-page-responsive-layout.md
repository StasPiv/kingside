# ADR-005: Адаптивный layout страницы игры

## Статус

Принято

## Контекст

Страница игры имеет фиксированный размер доски (560px) и не адаптируется к размеру viewport. На экранах стандартных ноутбуков (1366x768) блоки выходят за пределы видимой области, доска видна не полностью.

## Решение

Применяем принцип **board-first layout**: размер доски вычисляется динамически от доступного пространства viewport (min от ограничения по высоте и ширине).

Ключевые решения:

1. **Динамический boardWidth** — вычисляется через JS (window resize listener), а не фиксированное значение. CSS container queries пока не поддерживают передачу значений в React-компоненты.

2. **CSS `:has()` для game page** — `.main:has(.game-page)` убирает padding и max-width, чтобы игровая страница использовала всё доступное пространство.

3. **Mobile breakpoint 900px** — при ширине < 900px layout переключается на вертикальный (доска сверху, sidebar снизу).

4. **Sidebar flex layout** — секции move-list и chat делят доступную высоту через flex:1, синхронизируясь с высотой доски.

## Альтернативы

- **CSS-only решение (aspect-ratio + container queries)** — отклонено, т.к. react-chessboard требует числовой boardWidth prop.
- **Фиксированные breakpoints с несколькими boardWidth** — проще, но менее точно. Возможен как fallback.

## Последствия

- Доска всегда помещается в viewport без скроллинга
- Работает на экранах от 360px до 2560px
- Требуется хук `useResponsiveBoardSize` в GamePage
- Зависимость от CSS `:has()` — поддерживается всеми современными браузерами (baseline 2023)
