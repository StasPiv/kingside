# ADR-009: Редизайн кнопок действий в профиле пользователя

**Дата:** 2026-03-11
**Статус:** Принято
**Задача:** KS-413

---

## Контекст

Страница профиля (`ProfilePage.tsx`) содержит две кнопки действий:

1. **"Играть"** — ссылка на `/lobby`, расположена в заголовке секции "Последние партии"
2. **"Играть Puzzle Rush"** — ссылка на `/puzzle-rush`, расположена в заголовке секции "Puzzle Rush"

### Текущее состояние

Обе кнопки реализованы как компонент `<Link>` с классом `profile-section-link`:

```css
.profile-section-link {
  font-size: 14px;
  color: #81b64c;
  text-decoration: none;
  white-space: nowrap;
}

.profile-section-link:hover {
  text-decoration: underline;
}
```

**Проблемы текущей реализации:**
- Отображаются как обычные текстовые ссылки, а не как кнопки
- Маленький размер шрифта (14px) — визуально теряются
- Нет визуального отличия от навигационных ссылок
- Не соответствуют CTA (Call-to-Action) — главному призыву к действию
- Расположены в одну строку с `<h2>`, что снижает их заметность

### Существующая система кнопок в проекте

| Класс | Описание | Стили |
|-------|----------|-------|
| `button` (base) | Базовая кнопка | `bg: #7c83ff`, `padding: 10px 20px`, `border-radius: 6px`, `font-weight: 600` |
| `.play-btn` | Крупная кнопка действия | `font-size: 18px`, `padding: 14px 48px` |
| `.result-btn-primary` | Акцентная кнопка | `bg: #7c83ff`, hover: `#6366f1` |

Цветовая палитра:
- Синий/фиолетовый акцент: `#7c83ff`
- Зелёный акцент: `#81b64c`
- Фон тёмный: `#0f0f17` / `#16213e`

---

## Решение

### Рекомендуемые изменения

#### 1. Изменить тип элемента

Перейти от `<Link className="profile-section-link">` к полноценному визуальному CTA-элементу. Ссылка (`<Link>`) остаётся правильным HTML-элементом (навигация), но визуально должна выглядеть как кнопка.

#### 2. Расположение

Вынести кнопки из строки с заголовком `<h2>` в отдельный блок под секцией или перед контентом секции.

**Вариант A (рекомендован):** Кнопка отдельной строкой над контентом секции, выровнена влево или на всю ширину sidebar.

**Вариант B:** Сохранить inline-расположение, но значительно увеличить визуальный вес кнопки.

#### 3. Визуальный дизайн

Добавить новый класс `profile-action-btn` со стилями:

```css
.profile-action-btn {
  display: inline-flex;
  align-items: center;
  gap: 8px;
  padding: 10px 20px;
  background: #7c83ff;
  color: #fff;
  border-radius: 6px;
  font-size: 14px;
  font-weight: 600;
  text-decoration: none;
  transition: background 0.2s, transform 0.1s;
  white-space: nowrap;
}

.profile-action-btn:hover {
  background: #6366f1;
  text-decoration: none;
  transform: translateY(-1px);
}

.profile-action-btn:active {
  transform: translateY(0);
}
```

**Для кнопки "Играть"** — синий/фиолетовый (`#7c83ff`), соответствует основному CTA в лобби.

**Для кнопки "Играть Puzzle Rush"** — зелёный (`#81b64c`) или вариант с зелёным обводкой (secondary button), чтобы визуально дифференцировать.

#### 4. Иконки (опционально)

Если в проекте есть SVG-иконки или подключен icon-набор — добавить:
- ♟ (или иконку доски) для "Играть"
- ⚡ для "Играть Puzzle Rush"

Без иконок кнопки уже будут значительно лучше за счёт визуального веса.

#### 5. Лучшие практики (chess.com / Lichess)

- **chess.com**: Крупные зелёные CTA-кнопки с фиксированной высотой 48px+ на главной. В профиле — более умеренные, но всё равно styled кнопки.
- **Lichess**: Кнопки с border-radius, padding, accent-цвет (синий/оранжевый), чёткий hover-эффект.
- Общий паттерн: CTA в профиле не должен быть текстовой ссылкой — он должен быть заметен.

---

## Последствия

**Положительные:**
- Пользователь быстрее находит способ начать игру
- Согласованность с остальным дизайном кнопок в проекте
- Минимальные изменения: только CSS + HTML-класс

**Риски:**
- При Variant A (перенос кнопки) меняется структура JSX — нужно проверить адаптивность
- Нужно убедиться, что новый класс не конфликтует с существующими стилями `profile-section-link`

---

## Задача для Frontend

На основе этого анализа координатор создаёт задачу для frontend-разработчика со следующими требованиями:

1. Добавить CSS-класс `profile-action-btn` в `styles.css` согласно спецификации выше
2. В `ProfilePage.tsx` заменить `className="profile-section-link"` на `className="profile-action-btn"` для обеих кнопок
3. Опционально: рассмотреть отдельный вариант цвета для кнопки Puzzle Rush
4. Проверить внешний вид на мобильных breakpoints
