# KS-418: Переработка главной страницы (лобби) — архитектурный анализ

## Текущее состояние

### Что показывает лобби сейчас

`LobbyPage` — форма поиска партии. Она содержит:
- Выбор контроля времени (bullet/blitz/rapid/classical/custom)
- Фильтр рейтинга (относительный / абсолютный)
- Кнопка «Найти игру»
- Панель «Играть с ботом» (уровень, цвет, контроль)

Никаких ссылок на другие функции платформы на странице нет.

### Навигация (MainLayout)

Заголовок содержит:
- Логотип → `/lobby`
- Дроп-даун «Тренировка» → Задачи / Задача дня / Puzzle Rush
- Дроп-даун с именем пользователя → Профиль / Настройки / Выход

### Полный перечень функций платформы

| Функция | Маршрут | Доступность из лобби |
|---------|---------|----------------------|
| Игра онлайн (matchmaking) | `/lobby` (inline) | ✅ есть |
| Игра с ботом | `/lobby` (inline) | ✅ есть |
| Просмотр партии | `/game/:id/review` | ❌ только из профиля |
| Профиль / история партий | `/profile` | ❌ только в дроп-дауне |
| Задача дня | `/daily` | ❌ только в дроп-дауне |
| Браузер задач | `/puzzles` | ❌ только в дроп-дауне |
| Puzzle Rush | `/puzzle-rush` | ❌ только в дроп-дауне |
| Таблица лидеров Puzzle Rush | `/puzzle-rush/leaderboard` | ❌ нигде в лобби |
| Настройки | `/settings` | ❌ только в дроп-дауне |

**Вывод**: 6 из 8 функций платформы скрыты за дроп-дауном в заголовке. На
главной странице нет контекста о прогрессе пользователя.

## Архитектурное решение

### Концепция

Превратить лобби из формы поиска партии в **домашнюю страницу** —
информационный хаб, который:

1. Сохраняет первичный CTA — «Найти игру» и «Играть с ботом»
2. Показывает виджеты с краткой сводкой по каждой функции
3. Даёт прямые ссылки для перехода

Подход соответствует ограничениям: один разработчик, никакой новой
backend-логики — все необходимые API уже существуют.

### Новые API-запросы в LobbyPage

Все API уже существуют. Запросы выполняются параллельно при монтировании
компонента через `Promise.all`:

| Виджет | API | Метод |
|--------|-----|-------|
| DailyPuzzleWidget | `GET /api/puzzles/daily` | Проверить наличие задачи дня |
| PuzzleRushWidget | `GET /api/users/:id/puzzle-rush-stats` | best3, best5 |
| RecentGamesWidget | `GET /api/users/:id/games?take=3` | последние 3 партии |

**Особенность**: ошибки в виджетах не должны блокировать основной функционал
(поиск партии). Каждый виджет рендерится независимо, ошибки обрабатываются
локально.

### Изменения в LobbyPage.tsx

Существующий код `PlayPanel` (online + bot) остаётся без изменений.
Добавляется секция `SidePanel` с тремя виджетами.

Новое состояние в `LobbyPage`:

```ts
// Данные для виджетов (опциональны, не блокируют основной функционал)
const [dailyPuzzle, setDailyPuzzle] = useState<DailyPuzzlePreview | null>(null);
const [rushStats, setRushStats] = useState<PuzzleRushStats | null>(null);
const [recentGames, setRecentGames] = useState<GameRecord[]>([]);
const [widgetsLoading, setWidgetsLoading] = useState(true);

useEffect(() => {
  if (!user) return;
  Promise.all([
    api.get('/api/puzzles/daily').catch(() => null),
    api.get(`/api/users/${user.id}/puzzle-rush-stats`).catch(() => null),
    api.get(`/api/users/${user.id}/games?take=3`).catch(() => ({ data: [] })),
  ]).then(([daily, rush, games]) => {
    setDailyPuzzle(daily);
    setRushStats(rush);
    setRecentGames(games?.data ?? []);
  }).finally(() => setWidgetsLoading(false));
}, [user]);
```

## Задачи для frontend-разработчика

1. **Обернуть LobbyPage в двухколоночный grid** (desktop ≥ 1024px):
   - левая колонка: существующий `PlayPanel`
   - правая колонка: новый `SidePanel`

2. **Добавить параллельный fetch виджетов** через `Promise.all` при монтировании
   (только если `user` авторизован). Ошибки перехватывать локально.

3. **Реализовать `DailyPuzzleWidget`**:
   - запрос `GET /api/puzzles/daily`
   - показать рейтинг + темы (из `puzzle.themes`)
   - кнопка → `/daily`

4. **Реализовать `PuzzleRushWidget`**:
   - запрос `GET /api/users/:id/puzzle-rush-stats`
   - показать `best3`, `best5`
   - кнопки → `/puzzle-rush`, `/puzzle-rush/leaderboard`

5. **Реализовать `RecentGamesWidget`**:
   - запрос `GET /api/users/:id/games?take=3`
   - показать результат + соперник + timeControlType + дата
   - каждая строка → `/game/:id/review`
   - ссылка «Все партии» → `/profile`

6. **Добавить CSS** для `.lobby-layout`, `.lobby-widget` (минимально —
   max-width: 1200px, grid на десктопе, стиль карточек).

7. **Добавить i18n ключи** (EN + RU):
   - `lobby.dailyPuzzle`, `lobby.puzzleRush`, `lobby.recentGames`
   - `lobby.myRecord`, `lobby.solve`, `lobby.allGames`

8. **Протестировать адаптивность**: 375px, 768px, 1024px, 1440px.
