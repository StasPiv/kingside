## KS-1959 — Программа beginner-курса для Kingside

**Дата:** 2026-04-26
**Статус:** Черновик на обсуждение с пользователем
**Связанные:**
- KS-1958 — очистка БД от тестовых курсов (родитель этой работы)
- KS-1931 — концепция редизайна `/lessons` (Hero variant A ведёт сюда)
- ADR-024 Lessons module, ADR-025 SM-2 spaced repetition

> ⚠️ **Замечание о методе.** Документ — ресерч + предложение программы.
> Я опирался на свои знания о шахматной методике; ссылки на источники
> проверены по моей внутренней базе, но **не верифицированы веб-запросами**

---

### 0. TL;DR

- **ЦА Kingside-beginner:** взрослый/подросток, который знает как ходят
  фигуры, но играет меньше 800 рейтинга. Не для совсем нулевых
  «никогда не видел доску» — для них отдельный «Pre-beginner» (если
  вообще делать).
- **Программа: 12 уроков, ~4 часа суммарно**, разбита на 4 блока
  (правила-чеклист → шах/мат → ценность и тактика → стратегия+эндшпиль).
- **Подход:** «эндшпиль и тактика рано» (по Капабланке/Хайсману), не
  «дебюты и ловушки». Цель — не выучить открытие, а перестать терять
  фигуры и научиться доводить выигранную позицию.
- **Формат шагов:** TextStep (теория) → PuzzleStep (применение) → QuizStep
  (закрепление). PositionStep для интерактивных эндшпилей. VideoStep
  опционально, не критично для MVP.
- **Открытые вопросы (§7):** глубина дебюта (общие принципы или конкретный
  репертуар?), формат рокировки/en passant (отдельный урок или внутри
  правил?), порог выхода из курса (целиться на 800 или на 1200?), нужен
  ли Pre-beginner.

### 1. Задача и контекст

После очистки БД (KS-1958) каталог системных курсов пуст. Beginner-курс
будет первым реальным курсом и одновременно — точкой входа для P2 (новый
авторизованный юзер) и P3 (гость) согласно концепции KS-1931 (Hero
variant A: «Начни с курса для начинающих»).

**Что в нашем распоряжении (платформа):**

Поддерживаемые типы шагов
(`packages/shared/src/types/lessons.ts`, `apps/web/src/components/lessons/steps/`):

| Тип | Что умеет |
|---|---|
| `text` | Markdown + диаграммы (FEN), inline fenced FEN-блоки, иллюстрированная теория |
| `puzzle` | Тактическая задача из puzzle-базы либо по фильтру (тема, рейтинг), либо по списку id |
| `quiz` | Single/multi-choice вопрос, опционально с FEN-диаграммой над вопросом |
| `position` | Интерактивная позиция (drill): студент играет «правильную» сторону, движок отвечает |
| `game_review` | Разбор партии (просмотр с комментариями, ход за ходом) |
| `video` | Видео-урок (внешний видео-файл / встраивание) |

Дополнительные специализированные drill'ы в коде: `EndgameDrillStep`,
`OpeningDrillStep` (вероятно — обёртки над PositionStep с
предзаготовленным сценарием).

SM-2 spaced repetition (ADR-025) — после освоения урока он попадает в
очередь повторений. Beginner-курс рассчитан на повторное прохождение.

### 2. Обзор источников

> Группирую по типу: онлайн-платформы, книги, видеокурсы, методики
> для школ. Ссылки — для верификации chess-expert'ом перед публикацией.

#### 2.1 Онлайн-платформы

**chess.com Lessons → Beginner Path**
- URL: `chess.com/lessons` (раздел Beginner).
- Формат: интерактивные позиции + текст + мини-видео + задачи.
- Объём: ~50 уроков в Beginner-пути, по 5-15 минут каждый.
- Сильные стороны: интерактивность, обширный пул задач, прогресс
  трекается, доступно бесплатно (часть) + Diamond-подписка.
- Программа (по памяти, упрощённо): правила фигур → шах/мат → базовые
  маты (К+Ф vs К; К+Л vs К) → ценность фигур → принципы дебюта →
  базовая тактика (вилка, связка, double attack) → простой эндшпиль
  (К+П vs К, правило квадрата).
- Что взять: подробное разбиение «один урок — одна тема», много
  тренировочных задач после теории.

**lichess Study & Practice**
- URL: `lichess.org/practice`, `lichess.org/learn`.
- Формат: `/learn` — guided миниатюры (правила, шах-мат, ценность);
  `/practice` — interactive drills (К+Ф мат за 10 ходов, оппозиция,
  правило квадрата).
- Объём: `/learn` — ~40 миниатюр, `/practice` — ~30 категорий drills.
- Сильные стороны: бесплатно, минималистично, сразу через
  интерактивные позиции (мало текста).
- Что взять: формат «теория минимальная, drill максимальный» — для
  Kingside особенно подходит как баланс с chess.com (где много текста).

**ChessKid**
- URL: `chesskid.com`.
- Формат: для детей, геймификация (аватары, бейджи, мультики).
- Объём: ~150 уроков, кучи мини-игр.
- ЦА — дети 6-12 лет.
- Что взять: **в Kingside, наверное, не реюзаем** — у нас
  взрослая ЦА. Подачу через геймификацию учитываем как анти-паттерн
  для нашей платформы.

**Aimchess**
- URL: `aimchess.com`.
- Формат: data-driven анализ собственных партий + рекомендации
  тренировочных задач.
- ЦА: 800+ рейтинга, для тех, у кого уже есть партии для анализа.
- Что взять: **не для beginner-курса**. Скорее модель для будущего
  «Дневника ошибок» (KS-1928) и personalized recommendations.

**Chessable Beginner courses**
- URL: `chessable.com` (раздел Beginner).
- Формат: spaced repetition (MoveTrainer) + книжный текст.
- Известные beginner-курсы: «Smithy's Smashing Strategy», «Hellsten's
  Mastering Chess Strategy». Для совсем новичков — «Discovering
  Chess Openings» (Emms), «Capablanca's Chess Fundamentals» (digital
  edition).
- Сильные стороны: SRS встроен в платформу.
- Что взять: формат spaced repetition мы уже реализуем (ADR-025 SM-2).
  Подход «короткие концептуальные уроки + много дриллов» — заимствуем.

**Learnchess.com**
- URL: `learnchess.com`.
- Формат: для взрослых начинающих, упорядоченные уроки + задачи.
- Меньшая известность, но методически близка к нашей ЦА.
- Что взять: подход «начни с эндшпиля» (по Капабланке) для взрослых.

#### 2.2 Книги

**José Capablanca — «Основы шахматной игры» / «Chess Fundamentals» (1921)**
- Структура: эндшпиль → миттельшпиль → дебютные принципы → партии
  для разбора.
- Подход «эндшпиль первым» — спорный для современных курсов, но
  работает: учит думать об активности фигур до того как погружаться в
  дебютный хаос.
- Объём: ~150 страниц, классика.
- Что взять: фундаментальная структура «принципы важнее запомненных
  ходов»; конкретные эндшпильные позиции (К+Ф vs К, К+Л vs К) — почти
  каждый современный учебник их повторяет.

**Emanuel Lasker — «Учебник шахматной игры»**
- Структура: философско-методическая, последовательность от правил до
  стратегии.
- Подход: больше про мышление, чем про конкретные позиции.
- Современным новичкам тяжело читается — устарел стиль.
- Что взять: цитаты-афоризмы для эпиграфов уроков (если стилистика
  Kingside их допускает).

**Yasser Seirawan — «Play Winning Chess» (1990, переиздан 2003)**
- Структура: 4 принципа (force, time, space, pawn structure), вокруг
  которых строится теория.
- Подход: методичный, объясняет «почему», а не только «как».
- Объём: ~300 страниц.
- Часть серии «Winning Chess» (далее Tactics, Strategies, Endings,
  Openings).
- Что взять: четвёрка принципов «материал/время/пространство/структура» —
  отличный фреймворк для урока «как оценивать позицию».

**Артур Юсупов — «Шаг за шагом» (Build Up Your Chess, 9 томов)**
- Структура: 9 уровней от ~1500 до ~2200, каждый уровень — 24 главы
  по разным темам, с тестами в конце.
- Beginner-курс — это уровень 1 первого тома (Orange/Build Up 1).
- Подход: систематичный, тесты после каждой темы, scoring-система
  (если набрал <70% по главе — повторить).
- Что взять: модель «глава = тема + теория + 12 тестовых позиций
  + scoring». Совместимо с нашим SM-2 (повтор плохо освоенных уроков).

**Dan Heisman — «Everyone's First Chess Workbook»**
- ЦА: совсем новички (даже без знания правил).
- Структура: правила → ценность → одноходовая тактика → постепенно
  сложнее.
- Подход: «just enough theory, lots of practice». Принцип «counting
  exercises» — научи считать атакующих/защитников до того как
  обсуждать стратегию.
- Объём: ~250 страниц, преимущественно задачи.
- Что взять: упор на **counting** (атакующие vs защитники) — простой
  механический навык, который убирает 80% потерь фигур у новичков.

**Bonus: Susan Polgar — «Learn Chess the Right Way» (5 томов)**
- Beginner: тома 1-2.
- Формат: чисто задачи (200+ позиций на каждую тему).
- Структура: mate-in-1 → mate-in-2 → tactics → defence.
- Что взять: огромный пул задач для PuzzleStep'ов (если есть права).

#### 2.3 Видеокурсы

**Levy Rozman (GothamChess) — Beginner to Chess Master**
- Платформа: YouTube, Chessly.
- Формат: видеоуроки 10-30 минут, развлекательно.
- Программа: правила → принципы → дебют (London System рекомендует) →
  тактика → endgame essentials.
- Сильные стороны: entertainment-фактор, удерживает внимание.
- Слабые: фокус на запоминание дебюта (London) — спорная методика
  для долгосрочного развития.
- Что взять: тон и темп подачи; идею «один дебют для белых, один за
  чёрных» как простую отправную точку.

**Hanging Pawns Fundamentals**
- Платформа: YouTube.
- Формат: длинные методичные видео по темам.
- Программа: opening principles → middle game planning → endgame
  fundamentals.
- Сильные стороны: глубина объяснения, академический тон.
- Что взять: структуру блоков «принципы → планирование → эндшпиль».

**Daniel Naroditsky — Speedrun Series**
- Платформа: YouTube.
- Формат: GM играет с rating-floor, объясняет каждый ход.
- Не курс, а **обучение через примеры**. Полезен после прохождения
  beginner — для перехода 1000 → 1500.
- Что взять: формат «комментированные партии» для будущего Intermediate-
  курса, не Beginner.

**John Bartholomew — Chess Fundamentals + Climbing the Rating Ladder**
- Платформа: YouTube.
- Формат: 5-частный курс «Chess Fundamentals» (Undefended Pieces, Loose
  Pieces Drop Off, Coordinate Pieces, Typical Mistakes, Practical Endgames).
- Сильные стороны: чётко выделенные «концепты-якоря» (LPDO — Loose
  Pieces Drop Off, например).
- Что взять: **«концепты-якоря»** — короткие запоминающиеся принципы.
  Для Kingside можем сделать аналогичные «правила-памятки» в каждом
  уроке.

#### 2.4 Дет-методики и системные программы

**Steps Method (Cor van Wijgerden)**
- Голландская школа, используется во многих странах ЕС.
- 6 ступеней: Step 1 (учим правила) → Step 6 (~ FIDE 1900).
- Step 1 — это и есть «полный нулевой beginner»: правила, ценность,
  шах, мат-в-1, мат-в-2 — около 60 коротких уроков.
- Что взять: разбиение Step 1 — отличный шаблон для нашего «Pre-beginner»,
  если решим его делать. Для Kingside-beginner ориентируемся на
  Step 2-3 (после правил, до серьёзной стратегии).

**Dvoretsky / Yusupov Build Up (расширенно)**
- Школа Дворецкого: для перспективных юниоров.
- Подход «глубокий разбор каждой темы».
- Beginner-уровень — у Юсупова том 1 (см. §2.2).
- Что взять: scoring-система (см. §2.2 Юсупов).

**Polgar Method («Chess Tactics for Champions», Lazlo Polgar)**
- Знаменитый «Chess: 5334 Problems, Combinations, and Games».
- Подход «вышли тактикой» — массовое решение задач с детства.
- Сборник упражнений, не учебник.
- Что взять: пул задач (если есть лицензия).

| **Конкретный дебютный репертуар** | GothamChess: London System для всех | Capablanca, Seirawan, Yusupov: только принципы, без конкретного дебюта |

| **Counting как отдельная тема** | Heisman, Bartholomew: ★ | остальные: растворяется в тактике |
| **Видео в курсе** | chess.com (короткие), GothamChess (основа) | книги (нет), lichess (нет) |
| **Геймификация** | ChessKid: основа | взрослые курсы (Capablanca, Yusupov): минимум |

#### 3.3 Подходы к подаче — обобщение

Можно выделить **3 школы**:

1. **«Книжная»** (Capablanca, Seirawan, Yusupov, Heisman) — много
   текста, вдумчиво, эндшпиль рано, без ловушек. Развивает
   понимание. Минус — медленная отдача.
2. **«Платформенная»** (chess.com, ChessKid) — короткие интерактивные
   уроки, дебют рано, много гэймификации. Удерживает внимание. Минус
   — может закрепить «выучил London — играю плохо без него».
3. **«Тренажёрная»** (lichess Practice, Polgar) — почти без теории, всё
   через позиции. Для тех кто уже понял базу. Минус — без объяснения
   «почему» новичок забывает быстрее.

**Для Kingside предлагаю гибрид «книжная + тренажёрная»:** короткий
TextStep с фундаментальным принципом, затем PuzzleStep / PositionStep
для применения, в конце урока QuizStep для проверки понимания. Это
ближе к Yusupov-формату.

### 4. Программа Kingside Beginner

#### 4.1 Целевая аудитория

**ЦА:** взрослый или подросток (12+), который:
- Знает как ходят фигуры (включая рокировку, en passant, превращение —
  но допустимо если что-то подзабыл).
- Играл хотя бы 5-10 партий онлайн или вживую.
- Рейтинг ~ 0-800 (или нет рейтинга вовсе).
- Хочет «играть лучше», не «выучить шахматы для красоты».

**НЕ ЦА:**
- Совсем нулевые («не знаю как ходит конь») — для них нужен отдельный
  «Pre-beginner» (см. §7 открытый вопрос).
- Дети 6-10 лет (для них нужна геймификация, наша платформа на это не
  заточена).
- Игроки 1000+ — им курс будет скучен; их ведёт Intermediate.

**Порог выхода:** после прохождения курса игрок должен:
- Не зевать фигуры одноходовыми ударами в типичных позициях.
- Видеть базовую тактику (вилка, связка, открытое нападение) на
  глубину 2 хода.
- Доводить до победы К+Ф vs К и К+Л vs К без подсказки.
- Выигрывать К+П vs К когда есть опозиция.
- Не теряться в первых 10 ходах партии (знает принципы дебюта).

Это эквивалент **400-800 рейтинга на lichess** (~600-1000 chess.com).

#### 4.2 Структура: 4 блока × 3 урока = 12 уроков

```
Блок 1: ОСНОВЫ ИГРЫ          (3 урока, ~50 мин)
Блок 2: МАТУЕМ КОРОЛЯ        (3 урока, ~60 мин)
Блок 3: НЕ ТЕРЯЕМ ФИГУРЫ     (3 урока, ~60 мин)
Блок 4: НАЧАЛО И КОНЕЦ ПАРТИИ (3 урока, ~70 мин)
                              ────────────────────
                              ~4 часа суммарно
```

#### 4.3 Уроки

| # | Блок | Урок | Цель (что научится) | Шаги | Время |
|---|---|---|---|---|---|
| 1 | Основы | **Доска и нотация** | Узнаёт клетки по координатам (e4, h7), читает запись хода | text + quiz | 10 мин |
| 2 | Основы | **Что такое шах, мат, пат, ничья** | Различает шах / мат / пат; знает 3 типа ничьих (соглашение, повторение, 50 ходов) | text + puzzle (mate-in-1, distinguish stalemate) + quiz | 15 мин |
| 3 | Основы | **Особые ходы: рокировка, en passant, превращение** | Делает рокировку правильно; берёт на проходе; превращает пешку | text + position (рокировка drill) + quiz | 25 мин |
| 4 | Маты | **Мат ферзём и королём** | Доводит мат К+Ф vs К не более чем за 10 ходов | text (метод оттеснения) + position (drill) | 20 мин |
| 5 | Маты | **Мат ладьёй и королём** | Доводит мат К+Л vs К; знает «лестницу» | text + position (drill) | 25 мин |
| 6 | Маты | **Мат двумя ладьями** | Делает «мост» из двух ладей за 6-8 ходов | text + position (drill) + puzzle (mate-in-2) | 15 мин |
| 7 | Не терять | **Ценность фигур и размены** | Знает 1/3/3/5/9; считает материал; выгодные/невыгодные размены | text + puzzle (counting) + quiz | 20 мин |
| 8 | Не терять | **Counting: атакующие vs защитники** | Перед ходом считает: можно ли взять? Сколько атакующих, сколько защитников, кто бьёт первым? | text + puzzle (12 позиций «безопасно ли взять?») | 25 мин |
| 9 | Не терять | **Базовая тактика: вилка, связка, вскрытое нападение** | Узнаёт вилку коня/пешки; видит связку; находит вскрытое нападение | text + puzzle (15 задач, 5 на каждую тему) + quiz | 20 мин |
| 10 | Начало/конец | **Принципы дебюта** | Открывает партию по 4 принципам: центр / развитие / безопасность короля / не ходить дважды одной фигурой | text + game_review (1 хорошо разыгранный дебют + 1 «как не надо») + quiz | 25 мин |
| 11 | Начало/конец | **Король и пешка против короля** | Знает оппозицию; правило квадрата; проводит пешку в ферзи | text + position (3 drills: оппозиция, правило квадрата, ключевые поля) | 25 мин |
| 12 | Начало/конец | **Что дальше?** | Рекомендации как развиваться: играть медленные партии, разбирать свои, решать тактику ежедневно. Тест-аудит 15 позиций по всему курсу. | text + puzzle (15 mixed) + quiz (5 финальных вопросов) | 20 мин |

**Итого:** ~245 минут (~4 часа) активного времени без учёта повторений.

#### 4.4 Обоснование структуры

**Почему «не терять фигуры» важнее дебюта (блок 3 перед блоком 4):**
По Heisman'у и Bartholomew, новичок проигрывает партии не потому что
«плохой дебют», а потому что зевает фигуры. Counting и базовая тактика
дают **немедленную** отдачу — сразу после прохождения юзер начинает
выигрывать партии, которые раньше проигрывал.

**Почему маты до тактики (блок 2 перед блоком 3):**
Мат — это **финальный навык**. Если новичок не умеет домотать К+Ф vs К,
у него психологический барьер: «я не могу довести до конца, даже когда
выигрываю». Дать этот навык в начале — это уверенность.

**Почему дебютные принципы только в блоке 4:**
К моменту блока 4 у юзера уже есть инструменты понимать **зачем**
принципы (например, «контроль центра» имеет смысл только когда знаешь
counting). Иначе превращается в слепое запоминание.

**Почему нет конкретного дебютного репертуара:**
В соответствии с Capablanca/Seirawan/Yusupov: на beginner-уровне выучить
конкретный дебют = заложить вредную привычку «играю свой дебют, не думаю
о позиции». Курс даёт принципы; конкретные дебюты — на Intermediate
(если делать).

**Почему 12, а не 8 или 20:**
- 8 уроков — не помещается ни маты (3 разных), ни эндшпиль (минимум
  К+П vs К отдельным уроком), ни counting (требует отдельной темы).
- 20+ уроков — растягивает курс на >7 часов; новичок бросит на 6-7
  уроке.
- 12 — психологически «на 1-2 недели по 1 уроку в день».

#### 4.5 Формат шагов внутри урока

**Шаблон урока:**

```
1. TextStep            (3-7 мин)
   — Краткая теория с диаграммами FEN, 1-2 принципа максимум.
   — 1-2 диаграммы, не больше (KS-1929: интерактивная доска вместо
     статичных PNG).

2. PuzzleStep / PositionStep   (5-15 мин)
   — Применение теории. 5-15 задач или 1-3 drill'а.
   — Для тактических уроков: PuzzleStep с фильтром по теме.
   — Для эндшпильных: PositionStep / EndgameDrillStep.

3. QuizStep            (2-5 мин)
   — 3-5 вопросов с FEN-диаграммой над вопросом.
   — Single-choice: «какой ход выигрывает фигуру?»
   — Multi-choice: «отметь все позиции, где это вилка».
```

**Когда отклоняемся от шаблона:**
- Урок №3 (рокировка/en passant) — больше PositionStep'ов, потому что
  специальные ходы лучше освоить в drill'е, чем в задачах.
- Уроки 4-6 (маты) — основа PositionStep, текст минимальный.
- Урок 10 (принципы дебюта) — добавляется GameReviewStep (разобрать
  партию, где принципы соблюдены / нарушены).
- Урок 12 (финал) — расширенный QuizStep как «итоговый тест».

#### 4.6 SM-2 повторения

После прохождения каждого урока он попадает в очередь SM-2 (ADR-025).
- Уроки 4-6 (маты) и 11 (К+П vs К) — наиболее важно повторять
  (мышечная память для drill'ов).
- Уроки 1-3 (правила) — обычно достаточно одного повтора через 7
  дней.
- Уроки 7-9 (counting + тактика) — повторение раз в 3-7 дней первый
  месяц (тактическое зрение требует регулярной практики).

Это базовый sm-2 поведение, специальной настройки для beginner-курса
не нужно.

### 7. Открытые вопросы для пользователя

#### 7.1 Граница «новичок vs второй уровень»

**Вопрос:** где заканчивается beginner-курс и начинается следующий?

- Вариант **A** (рекомендую): курс покрывает 0-800 рейтинга, дальше —
  Intermediate с темами «миттельшпильное планирование», «изолятор и
  висячие пешки», «тяжёлофигурные эндшпили», «реальные дебюты». Это
  жирная пропасть в 400 пунктов рейтинга, но честная — внутри этого
  диапазона навыки разные.
- Вариант **B**: курс до 1200 — добавить ещё блок «миттельшпиль»
  (4-5 уроков). Тогда beginner-курс — 16-17 уроков, ~6 часов. Сложнее
  пройти за неделю.

#### 7.2 Pre-beginner (нулевой уровень)

**Вопрос:** делаем ли отдельный курс для тех, кто **не знает как
ходят фигуры**?

- Аргумент **за:** первый шаг для гостей с нуля. На рынке этим занимается
  ChessKid, но он для детей; для взрослых-нулевых ниша почти пуста.
- Аргумент **против:** маленькая аудитория. Большинство приходит на
  Kingside уже после 5-10 партий на других платформах. Первые 3 урока
  Kingside-beginner и так покрывают «как ходят» (нотация + правила +
  специальные ходы).
- Моя рекомендация: **не делать сейчас**. Если статистика покажет
  массовый отскок на уроке 1-3 — добавим Pre-beginner.

#### 7.3 Включать ли VideoStep

**Вопрос:** добавляем ли видео в beginner-курс?

- За: GothamChess-стиль удерживает внимание; видео хорошо для маты
  (показать движение фигур по доске).
- Против: производство видео — дорого. Без хорошего видео курс
  выглядит дешевле, чем без видео вообще.
- Моя рекомендация: **видео опционально, не блокирующее MVP**.
  Если есть готовый контент (например, чужие YouTube-видео по теме с
  разрешением на встраивание) — включаем. Иначе обходимся text +
  position для эндшпильных уроков.

#### 7.4 Дебютный репертуар

**Вопрос:** даём ли в курсе конкретный дебют (например, итальянскую за
белых) или только принципы?

- За конкретный: новичок ХОЧЕТ знать «что играть на 1.e4 e5» — это
  снимает тревогу.
- Против конкретного: на beginner-уровне это ловушка («зубрю Italian,
  а если соперник не отвечает по схеме — теряюсь»).
- Моя рекомендация: **только принципы в beginner**. Конкретный
  репертуар — отдельный (короткий) бонус-курс «Начни играть итальянскую»
  после beginner. Так сохраняем методическую чистоту, но даём то, что
  юзер просит.

#### 7.5 Локализация

**Вопрос:** курс пишется сразу на двух языках (en + ru) или сначала на
одном?

- Платформа i18n-ready, требует i18n-ключи на оба языка.
- Контент-первый язык влияет на стиль (если автор русскоязычный —
  начнёт с ru; перевод на en будет «русскость» иметь).
- Моя рекомендация: **уточнить у пользователя/chess-expert**, кто
  будет писать контент и на каком языке. От этого зависит план работ.

#### 7.6 Соотношение шагов в уроке

**Вопрос:** наш шаблон «text → puzzle → quiz» (см. §4.5) — это норма
или гибче?

- Если жёстко — упрощается ревью контента и UX предсказуем.
- Если гибко — можно в эндшпильных уроках почти убрать text.
- Моя рекомендация: **жёсткий каркас text→puzzle→quiz, но допускаются
  отклонения для эндшпильных** (4-6, 11) и финального урока (12).

#### 7.7 Использовать ли уже существующие задачи Lichess или нужен свой пул

**Вопрос:** для PuzzleStep'ов берём задачи из импортированной lichess-базы
(уже есть на платформе) или специально подбираем под курс?

- Из lichess-базы: огромный объём, фильтры по теме (`fork`, `pin` и
  т. д.) уже работают. Минус — задачи не «привязаны к уроку», могут
  быть слишком сложными или вне темы.
- Специально подбирать: точное соответствие теме, гарантированная
  сложность. Минус — ручной труд chess-expert по подбору 100+ задач.
- Моя рекомендация: **гибрид** — для тактических уроков (8-9) фильтр
  по теме из lichess-базы (с порогом по рейтингу 800-1200, чтобы
  не было слишком сложно); для нетактических уроков (1-3, 10) —
  составленные задачи из 5-15 позиций под конкретный урок.

### 8. Что НЕ входит в эту задачу

- **Содержательное наполнение уроков** (тексты, FEN-диаграммы,
  конкретные задачи, формулировки quiz-вопросов) — отдельная задача
  для chess-expert после согласования программы.
- **Конкретный pool задач** для каждого урока (подбор из puzzle-базы) —
  отдельная задача, опирается на §7.7.
- **Дизайн обложки курса и метаданные** (`coverUrl`, `audienceI18nKey`,
  `hookI18nKey` etc — поля DTO из KS-1931) — отдельная задача, можно
  параллельно.
- **Реализация в коде** (seed-фикстура, миграция системного курса в
  БД) — backend-задача после готовности контента.
- **Перевод** между языками — отдельная задача после готовности
  контента на исходном языке.
