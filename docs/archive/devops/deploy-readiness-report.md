## 4. Нерешённые риски

1. **Диск**: 84% заполнено — при росте логов и Docker-слоёв возможна нехватка места. Требуется периодическая очистка (`docker system prune`).
2. **Swap**: 237 MB swap используется — при пиковой нагрузке возможна деградация производительности.
3. **Shared-сервер**: nginx + php-fpm (стороннее приложение) конкурируют с Kingside за CPU и RAM.
