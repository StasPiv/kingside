# Git Workflow

## Ветки

- Каждая задача — отдельная ветка: `feature/KS-XX`
- Ветка создаётся от `main`
- После завершения работы — pull request в `main`

## Коммиты

- Формат сообщения: `KS-XX: краткое описание`
- Максимум 72 символа
- Без коммита задача не считается выполненной

## Pull Requests

- Изменения сливаются в `main` только через pull request
- PR должен содержать номер задачи в заголовке

## Правила для всех агентов

1. Перед началом работы — создать ветку `feature/KS-XX`
2. Коммитить изменения с указанием номера задачи
3. По завершении — открыть pull request
4. Без коммита и PR задача не может быть переведена в Done
