# ADR-170 рев.4 — фаза C: записка о результате (KS-5014)

Критерий §9: на 3–5 русских запросах-планах по тестовой позиции — возвращает
ли векторный поиск подходящие линии и верна ли их оценка.

**Дерево (§5.1):** первые ходы Maia∪SF-top3 (6 планов: c5, Nd7, a6, Cb4+, Ne7, h6);
вглубь ведёт Maia top-1, развилки Maia top-2 на 2-м и 4-м полуходе; стоп по
D_max=12 / мат / стабильный исход (Maia winProb). **Stockfish (depth 16) + trace
замерены ТОЛЬКО на листьях** (24 линии), не на внутренних узлах. Итог — 24 полные
линии по 12 полуходов.
**Запись (§5.2):** одно осмысленное LLM-описание смысла линии (структура, ход
борьбы, ключевые поля, исход) + один вектор Voyage voyage-3 (dim 1024);
`eval`/`outcome_prob`/`subterms` — отдельные поля вне эмбеддинга.
Данные — `phase-c.json`.

---

## Результаты по запросам (топ-5 по косинусу; «лучшая» — по сохранённой оценке для чёрных)

### 1. «надвинуть пешки королевского фланга и атаковать короля»
- В топ-5 есть линия с реальным наступлением на кор. фланге `…h6 Nc3 Cb4 … Nh4 … f4` (+0.56). Остальные — центральные размены.
- Лучшая по оценке из отобранных: `Ne7 Cg5 h6 C:e7 … c5` (−1.47 — сильная контригра чёрных).

### 2. «подорвать пешечный центр белых»
- Топ-5 — линии с подрывом `…c5`/вскрытием центра (в т.ч. `Nd7 O-O c5 c4 …`, `a6 … c5 c4`, `Qb6`-давление).
- Лучшая по оценке: `Ne7 Cg5 h6 Ch4 Qb6 … c5` (−1.31 — перевес чёрных на давлении по d4/b2).

### 3. «разменять фигуры и упростить позицию»
- **Точное попадание:** все топ-5 — разменные/упрощающие линии (`Cg5:e7`, `C:c5`, размены на d4, `Cb4+ Cd2 C:d2`).
- Лучшая по оценке: `Cb4+ Cd2 C:d2 Q:d2 … C:d3` (−0.32).

### 4. «спокойно развить фигуры и рокировать в безопасность»
- Топ-5 — развивающие линии с рокировкой (`…Nc6/Ne7/Nd7`, `O-O`).
- Лучшая по оценке: `Cb4+ Cd2 C:d2 … O-O … c5` (−0.41).

### 5. «начать активную игру на ферзевом фланге»
- Топ-5 — линии с ферзевой активностью (`Qb6`-давление, `…c5`, `c4/Nb5`, `Cb4+`-размены).
- Лучшая по оценке: `Ne7 Cg5 h6 Ch4 Qb6 … c5 … Nc6` (−1.31).

## Различает ли поиск линии (сравнение с прежними ревизиями)

**Да, лучше всех прошлых версий.** Три фактора совпали: (а) линии стали ПОЛНЫМИ
(12 полуходов) — в них реально есть размены, штурмы, подрывы, а не обрубок у корня;
(б) описание — осмысленный разбор смысла линии; (в) один вектор на линию.

- Запрос «размен/упрощение»: топ-5 — именно разменные линии (в рев.2/3 этот запрос
  проваливался — таких линий в коротком дереве не было).
- Запросы «подрыв центра», «ферзевый фланг», «развитие+рокировка»: топ-5 тематически
  связны.
- Кор.-фланговый штурм: релевантная линия (`…Nh4…f4`) попадает в топ-5, но не в топ-1
  — таких «чистых» штурмов Maia от этой позиции даёт мало.

Similarity умеренная (0.29–0.48): линии делят общий дебют (Каро-Канн, продвижение),
поэтому векторы близки — фундаментальное свойство «одна позиция → общий контекст»
(§107-риск снижен описанием «своего», но не снят полностью).

## Вердикт

**Поиск работает.** На полных линиях по §5.1 векторный поиск возвращает тематически
подходящие линии (особенно чётко — размен/упрощение, подрыв центра, ферзевая игра),
оценка отобранных линий берётся из отдельных полей записи (`eval`, `outcome_prob`)
вне эмбеддинга. Замер Stockfish+trace выполнен только на листьях (24 линии), внутри
линий движок не вызывался — ход вели Maia-политики. Остаточная слабость — умеренная
similarity из-за общего дебютного контекста.
