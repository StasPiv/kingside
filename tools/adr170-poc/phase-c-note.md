# ADR-170 рев.3 — фаза C: записка о результате (KS-5013)

Критерий §9: на 3–5 русских запросах-планах по тестовой позиции — возвращает
ли векторный поиск подходящие линии и верна ли их оценка. Плюс (§Gherkin KS-5013):
различает ли поиск линии лучше рев.2.

**Схема (рев.3):** одна запись на линию = **одно осмысленное описание** смысла
линии (дебют, пешечная структура, планы сторон, ключевые поля, следствие ходов),
сгенерированное агентом в сессии, с упором на distinctive «своё» линии + **один
вектор** Voyage voyage-3 (dim 1024). `eval`, `outcome_prob`, `subterms` — отдельные
поля, **вне** эмбеддинга. Порядок: сначала линии из дерева (`tree.json`), затем
комментарий к каждой фактической линии (`descriptions.json`).
**Позиция:** Каро-Канн с продвижением (`…b KQkq - 1 5`), база +0.41 в пользу белых.

---

## Результаты по запросам (топ-5 по косинусу + оценка отобранных линий)

### 1. «надвинуть пешки королевского фланга и атаковать короля»
- Топ-5: `h6 O-O` (0.53), `Nd7 O-O a5 a4` (0.50), `Ne7 O-O Ng6` (0.49), `Ne7 c3 Ng6` (0.46), `Ne7` (0.46).
- **Ответ:** отобраны линии кор.-фланговой профилактики `…h6` и перевода коня `…Ng6` (давление на e5) — тематически близко. Лучшая по оценке — `h6 O-O` (+0.58, WDL 16/83/0).

### 2. «подорвать пешечный центр белых»
- Топ-5: `Ne7 c3 Ng6` (0.42), `h6 O-O Nd7` (0.38), `c5 O-O cxd4 Nxd4` (0.37), `a6 O-O` (0.37), `a6` (0.36).
- **Ответ:** поиск поднял линии давления на центр (`…Ng6` по e5, размен `…cxd4`), но чистый подрыв `…c5` в топ-1 не вышел. Лучшая по оценке — `a6` (+0.57). Запрос обработан частично.

### 3. «разменять фигуры и упростить позицию»
- Топ-5: `Ne7 O-O` (0.37), `c5 c3 Nc6 O-O` (0.35), `c5 O-O Nc6` (0.35), `Nd7 O-O a5 c4` (0.35), `c5 O-O cxd4` (0.34).
- **Ответ:** явной разменной линии в базе нет; отобраны спокойные развивающие линии. Лучшая по оценке — `c5 c3 Nc6 O-O` (+0.31, ближайшая к равенству).

### 4. «спокойно развить фигуры и рокировать в безопасность»
- Топ-5: `h6 O-O Nd7` (0.35), `Nd7` (0.33), `h6 O-O a6` (0.32), `c5 O-O Nc6` (0.32), `c5 O-O` (0.31).
- **Ответ:** отобраны линии с развитием коня и рокировкой — по смыслу верно. Лучшая по оценке — `c5 O-O` (+0.34).

### 5. «начать активную игру на ферзевом фланге»
- Топ-5: `Nd7 O-O a5 a4` (0.37), `Nd7 O-O a5 c4` (0.34), `Nd7 O-O a5` (0.33), `Nd7 O-O c5 c4` (0.33), `a6` (0.32).
- **Ответ:** топ-4 из 5 — именно ферзевое наступление `…a5(–a4)` — точное попадание в план. Лучшая по оценке — `Nd7 O-O a5 c4` (+0.37, близко к равенству).

## Различает ли поиск линии лучше рев.2

**Да, заметно лучше по кластеризации плана.** Осмысленные описания дают поиску
семантику плана, а не список ходов:

| Запрос | рев.2 (описание = ходы) | рев.3 (описание = смысл линии) |
|---|---|---|
| штурм фланга | `h6`/`a6` вперемешку, sim ≤0.49 | `h6` + переводы `…Ng6` на e5 — тематично, sim до 0.53 |
| ферзевый фланг | шум `h6`/`a6`, тема не выделена | топ-4/5 — именно `…a5–a4` (точный план) |
| подрыв центра | `h6 O-O` (мимо) | `…Ng6`/`…cxd4` (давление на центр), но не `…c5` в топ-1 |
| развитие+рокировка | `h6 O-O a6` | линии с развитием коня и рокировкой |

- Ферзевый запрос: рев.2 — промах, рев.3 — точное попадание в `…a5` кластер.
- Штурм фланга и развитие: рев.3 отбирает тематически связанные линии.
- Подрыв центра `…c5` — по-прежнему слабое место: описания разных планов делят общий
  дебютный контекст (Каро-Канн, цепь d4–e5), и это тянет similarity к середине
  (0.31–0.53). §107-риск снижен, но не снят полностью.

## Вердикт

**Поиск работает и различает линии лучше рев.2.** Осмысленные описания смысла
линии повысили релевантность (особенно ферзевый и кор.-фланговый планы кластеризуются
верно). Оценка отобранных линий берётся из отдельных полей записи (`eval`,
`outcome_prob`) вне эмбеддинга — по §4 рев.3. Остаточная слабость — близкие описания
у линий, делящих дебют/структуру (подрыв `…c5` не всегда в топ-1); это фундаментальное
свойство «одна позиция → общий контекст», кандидат на доработку (сильнее выделять
distinctive-часть, либо гибрид с оценкой/структурой при ранжировании).
