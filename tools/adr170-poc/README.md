# ADR-170 PoC — конвейер дерева веток (KS-5009)

Разовый скрипт (не сервис). Строит дерево вариантов от тестовой позиции
ADR-170 §3 и сохраняет запись на каждую ветку по схеме §4 — БЕЗ описаний
и эмбеддингов (это следующая задача, фаза наполнения C).

## Запуск

```bash
npx tsx tools/adr170-poc/build-tree.ts
```

Выход: `tools/adr170-poc/tree.json`.

## Инструменты

- **Maia policy** (человеческие ходы) — `@kingside/maia-core` +
  `tools/maia3/maia3_simplified.onnx`, ELO 1500.
- **Оценка / WDL / сильнейшие ходы** — системный Stockfish 18
  (`/usr/games/stockfish`), depth 14, MultiPV 4.
- **63+ подкомпоненты** — форк trace `tools/stockfish-trace/src/stockfish`
  (`eval json`, NNUE выключен).

## Схема ветки (§4)

`root_fen`, `moves_uci` / `moves_san`, `leaf_fen`, `depth`, `stop_reason`,
`source` (maia/sf), `eval` (пешки, перспектива белых), `outcome_prob`
(W/D/L 0..1), `subterms` (агрегат по 65 id, нетто белые = white−black),
`subterms_raw` (сырые per-square записи движка), `subterms_total`.
`baseline` в шапке — та же оценка/подкомпоненты для корня (для дельт).

## Пороги (эмпирические, §8)

У корня широко (Maia до массы 0.82 / prob≥0.06, до 6 ходов + SF top-3),
вглубь узко. Глубина ≤ 4 полухода. Обход в ширину (BFS) — сперва все планы
у корня, затем углубление; бюджет 40 веток.

## Результат прогона

40 веток, 6 разных первых ходов/планов: `c5` (подрыв центра), `Nd7`/`Ne7`
(развитие), `h6` (кор. фланг), `Bb4+` (связка/шах), `a6` (ферз. фланг).
Каждая запись содержит eval, outcome_prob и 65 подкомпонент. Оба
Gherkin-сценария KS-5009 выполнены.
