# PoC ADR-168 — вектор позиции из скрытого слоя Lc0 (KS-4989)

Проверка гипотезы ADR-168: пригоден ли скрытый слой сети Lc0 как пространство
похожести позиций (расстояния отражают **характер/исход**, а не число сделанных ходов).

## Что реализовано
- `lc0poc.py` — парсинг весов Lc0 (`.pb.gz`, dequant uint16, fold BN по
  `network_legacy.cc`), кодирование `FEN→112 плоскостей`
  (`INPUT_CLASSICAL_112_PLANE`, `HistoryFill=fen_only`), прямой проход ствола
  (SE-ResNet) в numpy по `network_blas.cc`/`se_unit.cc`. Извлечение вектора со
  скрытого слоя, пулинг `flat` (C·64) или `gap` (среднее по 64 клеткам, C).
  **Нормализация перспективы «к ходу»** (главная ловушка §5): при ходе чёрных
  доска зеркалится (`board.mirror()`), сравнение — в единой системе; плоскость
  «чей ход» сохраняется как в оригинале Lc0. Метрика — косинус.
- `data.py` — выборка позиций из мастер-партий (Carlsen.pgn, 405 партий),
  детерминированная структурная метка (6 классов пешечной структуры).
- `run_all.py` — валидация прямого прохода + 3 теста ADR §4 с базовыми линиями.

## Сети
- `744706.pb.gz` — **самоигровая** сеть Lc0 (SE-ResNet 10×128, WDL) —
  соответствует обоснованию ADR (обучение на исход/лучший ход). **Основная.**
- `maia-1500.pb.gz` — Lc0-архитектура, но обучена имитировать ход человека 1500.
  Используется как эталон для **валидации прямого прохода** (у неё корректно
  декодируется голова value → сверка со Stockfish).

Скрытый слой транформерных сетей (BT/T-серии) в numpy не считается; реализация
их attention-body — вне объёма PoC.

## Валидация прямого прохода (обязательна до тестов)
- **Перспектива:** вектор позиции white-to-move и её цвето-зеркального двойника
  black-to-move различаются **только** плоскостью «чей ход» (rel. 3–5%), т.е.
  ориентация доски нормализована верно. Ловушка §5 закрыта.
- **Голова value vs Stockfish** (Maia, несбалансированные позиции): corr 0.69,
  оценки осмысленны (ферзь вперёд → +0.85). Прямой проход корректен.
- **Ствол 744706** проверен независимо от его головы value: линейная проба
  «знак материала» из ствола = 0.79 ≈ Maia 0.82 (эталон корректного ствола).
  Ствол 744706 валиден; расхождение головы value 744706 — отдельный дефект
  декода головы, на тесты не влияет (тесты используют только ствол).

## Результаты (сеть 744706, самоигровая; слои 5/7/10 из 10; n=250 для теста 2)

Пороги зафиксированы ДО прогона: T1 — доля соседей выше случайной базы с запасом;
T2 (критичный) — медиана расстояния после зевка заметно больше, чем после тихого
хода (порог: отношение >1.3 и доля(зевок>тихий)>0.6 на средне-позднем слое);
T3 — линейная проба читает свойство выше случайного.

**Тест 1 «Соседи»** (top-10, исключены соседи из той же партии), база 0.209:
| слой·пулинг | доля одной метки | lift |
|---|---|---|
| b5-flat | 0.357 | **×1.71** |
| b7-flat | 0.333 | ×1.59 |
| b10-flat | 0.310 | ×1.48 |
| b5-gap | 0.303 | ×1.45 |

→ **ПРОЙДЕН** с запасом.

**Тест 2 «Характер, а не ходы» (КРИТИЧНЫЙ)**, косинус-расстояние от позиции:
| слой·пулинг | тихий (лучший) | зевок ≥300cp | случайный | зевок/тихий | доля(зевок>тихий) |
|---|---|---|---|---|---|
| b5-flat | 0.303 | 0.309 | 0.301 | ×1.02 | 0.612 |
| b7-flat | 0.340 | 0.350 | 0.341 | ×1.03 | 0.676 |
| b10-flat | 0.380 | 0.399 | 0.381 | ×1.05 | 0.600 |
| b7-gap | 0.043 | 0.056 | 0.044 | **×1.32** | 0.664 |
| b10-gap | 0.094 | 0.128 | 0.109 | **×1.36** | 0.624 |

→ **ПРОЙДЕН предельно, только с пулингом `gap` на средне-позднем слое** (×1.32–1.36).
С пространственным пулингом `flat` расстояние определяется фактом перемещения
фигуры, а не сменой характера (×1.0) — это ровно ловушка «число ходов» из §2.
Порядок тихий < случайный < зевок соблюдён (gap).

**Тест 3 «Проба смысла»** (линейная проба из вектора):
- «есть проходная» (вычислимо), база 0.689: **b5-flat 0.823** → ПРОЙДЕН с запасом.
- «кто лучше» (знак оценки SF, |e|>50cp), база 0.622: **b10-flat 0.689** (+0.067) →
  выше случайного слабо.

## Вердикт
Пространство похожести **условно пригодно, но со слабым критичным сигналом.**
- T1 и T3(проходная) — уверенно да.
- T2 (критичный) — сигнал присутствует и направлен верно (зевок дальше тихого),
  но модест (×1.3) и виден лишь при `gap`-пулинге на средне-позднем слое; при
  `flat` теряется в «геометрии хода».
- T3(кто лучше) — едва выше случайного.

По §4 это **пограничное подтверждение**, не чистый зелёный свет: скрытый слой
классической самоигровой Lc0 несёт «характер», но выделяется он слабо и требует
правильного представления (`gap`, средне-поздний слой). Перед раскрытием φ*/планов
(§6) — решение координатора/architect: (а) принять модест-сигнал с gap-пулингом,
либо (б) перепроверить на сильной трансформерной сети (BT/T) с валидированным
прямым проходом (сборка lc0 → ONNX → onnxruntime), чтобы понять, усиливается ли
критичный сигнал.

## Воспроизведение
```
# окружение (numpy, onnxruntime — системные; доустановить в /tmp/ks4989-libs):
python3 -m pip install --target=/tmp/ks4989-libs onnx scikit-learn grpcio-tools meson ninja
# proto: скомпилировать libs/lczero-common/proto/net.proto -> /tmp/ks4989-proto/net_pb2.py
# сети:
curl -L https://storage.lczero.org/files/networks-contrib/744706.pb.gz -o /tmp/744706.pb.gz
curl -L https://github.com/CSSLab/maia-chess/raw/master/maia_weights/maia-1500.pb.gz -o /tmp/maia-1500.pb.gz
# мастер-партии: pgnmentor Carlsen.zip -> /tmp/ks4989/Carlsen.zip
python3 data.py                 # -> fens.txt (4000 позиций)
NET=/tmp/744706.pb.gz python3 run_all.py "5,7,10" 250
NET=/tmp/maia-1500.pb.gz python3 run_all.py "2,4,6" 250   # эталон-валидация
```
Требуется Stockfish (`/usr/games/stockfish`) для тестов 2/3b.
