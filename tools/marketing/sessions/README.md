# Сессии основателя для браузерного контура marketing (ADR-161, KS-4904)

Здесь живут перенесённые залогиненные сессии (Playwright storageState):

```
x.storageState.json        # 0600, В GIT НЕ КОММИТИТСЯ
reddit.storageState.json   # 0600, В GIT НЕ КОММИТИТСЯ
<platform>.lock            # служебный lock «платформа занята», создаётся/удаляется сам
```

В git из этой папки живёт только этот README. Файлы `*.storageState.json` дают
полный доступ к аккаунту до ревокации сессии — обращаться как с паролем.

## 1. Захват (на своей машине, однократно на платформу)

Требования: Node 20+, репозиторий, установленный Playwright:

```bash
npm i playwright && npx playwright install chromium
```

Захват (откроется обычное окно браузера — войдите как всегда, включая 2FA;
скрипт сам заметит вход, сохранит файл и закроет окно):

```bash
node tools/marketing/session-capture.mjs x
node tools/marketing/session-capture.mjs reddit
```

Файл появится в текущей папке: `x.storageState.json` / `reddit.storageState.json`.

## 2. Перенос на сервер

```bash
scp x.storageState.json reddit.storageState.json <сервер>:<путь к репо>/tools/marketing/sessions/
ssh <сервер> 'chmod 600 <путь к репо>/tools/marketing/sessions/*.storageState.json'
```

Локальные копии после переноса удалить: `rm -P *.storageState.json` (или обычный `rm`).

## 3. Обновление / смерть сессии

- Агент после каждого использования сам перезаписывает storageState свежими
  cookie — при регулярной работе сессия живёт неделями/месяцами без вас.
- Если платформа сессию убила (смена пароля, ревокация, антифрод), агент
  останавливает контур этой платформы и присылает в Telegram
  «сессия X умерла — переснимите». Тогда повторить п.1–2 для этой платформы.
- Принудительная ревокация (если файл мог утечь): X → Settings → Security →
  Sessions → log out session; Reddit → Settings → выйти со всех устройств
  (или смена пароля). После ревокации файл бесполезен.

## 4. Как агент использует сессию (справочно)

Общий модуль `tools/marketing/session-lib.mjs`:
- `withSession('x', fn)` — lock платформы (один браузер на платформу),
  контекст из storageState, проверка входа по маркерам UI, работа,
  обратная запись состояния, закрытие;
- детект разлогина: явные маркеры анонимного UI → стоп + Telegram;
  «страница не доросла» разлогином не считается;
- паролей в системе нет вообще (ADR-161 §7) — только перенесённый storageState.
