# Контур публикации с Telegram-подтверждением (ADR-161 §4, KS-4906)

Ни один комментарий не публикуется без явного ответа основателя. Темп задаёт человек.

## Порядок (исполняет marketing-агент)

1. **Черновик.** Цикл мониторинга находит кандидата → `addDraft({platform, url, text, subreddit, note})`
   (publish-lib) → отправка основателю через выделенного бота @kingside_marketing_bot
   (KS-4908): `node tools/marketing/marketing-bot.mjs send <draft-id>` — двумя сообщениями:
   ```
   ЧЕРНОВИК <draft-id> [reddit|x] — <1 строка контекста>
   <прямая ссылка на тред/твит>
   Ответь: ok — публикую как есть · skip — не публикуем · свой текст — публикую с правкой
   ```
   Вторым сообщением — сам текст (готовый к публикации).
2. **Ответ основателя** приходит боту и забирается `marketing-bot.mjs poll`
   (getUpdates, webhook не используется; poll зовётся каждым циклом и после
   отправки черновика) → `resolveReply(ответ)`; approved публикуется poll'ом
   сразу через publish.mjs, результат уходит основателю тем же ботом.
   Координаторный `telegram_send` для черновиков НЕ используется (KS-4908):
   `ok` → approved как есть; `skip` → skipped; иной текст → approved с текстом основателя.
   **Привязка к черновику**: голый `ok`/`skip`/текст принимается ТОЛЬКО когда ждёт
   ровно один черновик; при нескольких активных ответ обязан начинаться с id
   (`d2-20260712 ok`, `d2-20260712 skip`, `d2-20260712 <свой текст>`), иначе агент
   переспрашивает со списком id и ничего не публикует.
3. **Публикация.** `node tools/marketing/publish.mjs <draft-id>` — только для approved:
   лимиты (`actionDenied`: дневные потолки, ≤2/сабреддит, пауза ≥10 мин) → сессия →
   детект капчи/челленджа → заполнение формы → счётчики → строка в published.md.
4. **Таймаут 4 часа** без ответа → черновик сгорает (`expireDrafts`, зовётся каждым циклом);
   сгоревшее не публикуется и не переспрашивается (вечнозелёное — в следующий утренний бриф).

## Стоп-кран

Капча/челлендж/разлогин при любом шаге → платформа останавливается флагом
`halted` в actions-state.json (все публикации отклоняются), основателю уходит
`telegram_send` с причиной. Ретраев нет. Снятие — только вручную после разбора:
`node tools/marketing/publish.mjs --resume <platform>`.

## Коды выхода publish.mjs

`0` опубликовано · `2` черновик не найден · `3` разлогин (halt + переснять сессию) ·
`4` лимит или черновик не approved · `5` стоп-кран сработал · `1` прочее.
