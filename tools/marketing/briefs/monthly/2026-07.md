## M3 (15.07): YouTube-видео месяца — сценарий

**Тема: «Тренировка по расписанию: как Kingside учит тебя на твоих же партиях» (6–8 мин)**

1. Хук (0:00–0:30): «Все знают, что разбирать свои партии полезно. Никто этого не делает.
   Покажу систему, которая делает это за тебя — по расписанию».
2. Проблема (0:30–1:30): курсы-универсалы не про твои ошибки; мотивация умирает без ритма.
3. Настройка (1:30–3:00): скринкаст — Настройки → Расписание занятий → две тренировки
   («Тактика» будни 19:00, «Эндшпили» сб 10:00), импорт партий с chess.com/lichess или PGN.
4. Занятие (3:00–5:30): уведомление → /study → урок: шаги из своих партий, задачи, доигрывание;
   финальный score.
5. История (5:30–6:30): прогресс по каждой тренировке отдельно, оценки 0–100.
6. Финал (6:30–7:00): «Бесплатно, без подписки. Ссылка в описании». Ссылки: kingside.site +
   статья /blog/flexible-training-schedules.

Обложка: доска + будильник, титр «Тренировка по расписанию». Теги: chess training,
chess improvement, учиться шахматам.
